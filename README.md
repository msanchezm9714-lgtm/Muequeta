# Muequetá — sitio web

Sitio estático (HTML, CSS y JavaScript). No necesita instalación ni build. Todos los archivos están en la misma carpeta.

- Páginas: `index.html`, `servicios.html`, `equipo.html`, `contacto.html`
- Estilos y código: `main.css`, `main.js`, `site-config.js`
- Imágenes: archivos `.webp` y `.png`

## Datos editables
Contacto (WhatsApp, teléfono, correo, Instagram, Facebook) y zonas: `site-config.js`.

## Antes de que Google lo indexe
Quitar la línea `<meta name="robots" content="noindex,nofollow">` de las cuatro páginas HTML.

## Publicar
Funciona en cualquier hosting estático (Vercel, GitHub Pages, Netlify).
